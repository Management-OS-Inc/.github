# Management-OS-Inc/.github

This repository holds two things for the [Management OS](https://mgmt-os.ai) organization on GitHub:

- **The organization profile** shown at [github.com/Management-OS-Inc](https://github.com/Management-OS-Inc): [`profile/README.md`](profile/README.md) and its images in [`profile/assets`](profile/assets).
- **Default community files** that apply to every repository in the organization that doesn't have its own: [SECURITY.md](SECURITY.md), [SUPPORT.md](SUPPORT.md), [CONTRIBUTING.md](CONTRIBUTING.md) and the issue forms in [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE).
