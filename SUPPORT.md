# Getting help

| You need | Go here |
|---|---|
| Setup in Claude, Gemini, Grok or another assistant | [mgmt-os.ai/help/ai-assistants](https://mgmt-os.ai/help/ai-assistants) |
| Answers about the app | [mgmt-os.ai/help](https://mgmt-os.ai/help) |
| Your account, billing or credits | In the app: **Settings**, then **Billing**. Or email [support@mgmt-os.ai](mailto:support@mgmt-os.ai) |
| Anything else | [support@mgmt-os.ai](mailto:support@mgmt-os.ai) or [mgmt-os.ai/support](https://mgmt-os.ai/support) |
| Service status | [mgmt-os.ai/status](https://mgmt-os.ai/status) |
| A security problem | Don't open an issue. See [SECURITY.md](https://github.com/Management-OS-Inc/.github/blob/main/SECURITY.md) |
| A bug in a file in one of our repositories | Open an issue in that repository |

**Issues are public.** Never paste CRM records, call notes, emails, names or anything else about a customer, a deal or a person into an issue. Describe the problem in general terms, and email support if we need the details.
