### Use it where you work

Sign in once with your Management OS account. Every assistant tool is read-only: nothing is sent, changed or deleted on your behalf.

| Where you work | Status | How to connect |
|---|---|---|
| **Claude**: chat, Cowork, mobile and Claude Code | Available | Install the [plugin](https://github.com/Management-OS-Inc/management-os-plugin#quick-install), or add the connector |
| **Gemini**: CLI, Gemini app and Gemini Enterprise | Supported | CLI extension; Gemini app on personal US accounts; Enterprise on request. [Setup](https://github.com/Management-OS-Inc/management-os-plugin#install-by-platform) |
| **Grok** | Available | Custom connector on grok.com |
| **Hermes Agent** and **OpenClaw** | Supported | Add the server URL, then sign in |
| **Cursor, VS Code, GitHub Copilot, Codex** | Supported | Add the server URL, then sign in |
| **ChatGPT** | In review | Listed in ChatGPT's app directory once approved |

Step-by-step setup for each assistant: [mgmt-os.ai/help/ai-assistants](https://mgmt-os.ai/help/ai-assistants).

You pay for finished work, never tokens. Plans start at $149 a month with a 30-day free trial that includes 100 credits: [pricing](https://mgmt-os.ai/pricing).

**See it before you connect:** a made-up deal you can paste into your assistant, with excerpts of the real read and coaching it produces. [Try the sample deal](https://github.com/Management-OS-Inc/management-os-plugin#try-it-on-a-sample-deal).

### Trust

- Assistant tools receive only what your assistant sends in a call. Evidence is used for that call only. Management OS keeps a one-way fingerprint of it and clears each read within 24 hours.
- Management OS does not train models on customer data.
- Security posture, sub-processors and our disclosure policy: [mgmt-os.ai/trust](https://mgmt-os.ai/trust). Found a vulnerability? See our [security policy](https://github.com/Management-OS-Inc/.github/blob/main/SECURITY.md).
